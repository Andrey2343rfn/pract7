# Практична робота №7

Тема: Обробка та аналіз IoT-даних в openHAB.

## Склад архіву

- Zvit_praktychna_robota_7.docx, звіт із результатами та знімками екрана.
- processing.rules, правила обробки температури й вологості.
- rrd4j.persist, налаштування збереження історії.
- home.sitemap, графіки за годину та добу.
- screenshot_01.png ... screenshot_09.png, підтвердження виконання.

## Декларація використання ШІ

Інструмент: ChatGPT від OpenAI.
Мета: покрокова допомога з налаштуванням openHAB, пояснення команд термінала, підготовка прикладів конфігурацій RRD4j, правил Rules DSL, sitemap та оформлення звіту.
Приклади запитів: «Допоможи налаштувати збереження IoT-даних у RRD4j», «Напиши правило для середньої, мінімальної та максимальної температури», «Як перевірити аномалію температури понад 5 °C?», «Підготуй звіт українською мовою».
Використані фрагменти: код processing.rules, rrd4j.persist, home.sitemap, пояснювальні тексти звіту.
Самостійні дії та перевірка: встановлення і запуск openHAB, створення елементів, введення тестових даних через REST API, перевірка середньої, мінімальної та максимальної температури й вологості, перевірка повідомлення про аномалію в журналі, відкриття графіків Basic UI, зняття скриншотів.
Почасове правило налаштоване, але окремого підтвердження виконання за розкладом не надано.
